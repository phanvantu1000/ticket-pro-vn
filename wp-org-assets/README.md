# Hướng dẫn Chuẩn bị Assets cho WordPress.org (Banner, Icon, Screenshot)

Khi plugin được duyệt, bạn sẽ đưa các file hình ảnh này vào thư mục `assets/` của SVN (nằm ngang hàng với `trunk/`, không nằm trong thư mục code plugin).

## 1. Plugin Icons (Hiển thị trong kết quả tìm kiếm plugin)
* **icon-128x128.png** hoặc **icon-128x128.jpg**: Độ phân giải chuẩn (128x128 px).
* **icon-256x256.png** hoặc **icon-256x256.jpg**: Độ phân giải Retina (256x256 px - khuyên dùng).
* Hoặc file vector SVG: **icon.svg**.

## 2. Plugin Banners (Hiển thị đầu trang plugin trên WordPress.org)
* **banner-772x250.png** hoặc **banner-772x250.jpg**: Độ phân giải chuẩn (772x250 px).
* **banner-1544x500.png** hoặc **banner-1544x500.jpg**: Độ phân giải Retina (1544x500 px - khuyên dùng).
* Khuyến nghị: Thiết kế bắt mắt, đồng bộ màu sắc thương hiệu, hiển thị tên plugin và slogan ngắn gọn.

## 3. Screenshots (Ảnh chụp màn hình tính năng)
Tên file phải khớp với số thứ tự mô tả trong mục `== Screenshots ==` của file `readme.txt`:
* **screenshot-1.png**: Khớp với mục 1 trong readme.txt (Giao diện Quản lý vé Admin).
* **screenshot-2.png**: Khớp với mục 2 trong readme.txt (Chi tiết hội thoại & phân công agent).
* **screenshot-3.png**: Khớp với mục 3 trong readme.txt (Trang Cài đặt tệp đính kèm & bộ lọc).
* **screenshot-4.png**: Khớp với mục 4 trong readme.txt (Form gửi vé phía người dùng).
* **screenshot-5.png**: Khớp với mục 5 trong readme.txt (Danh sách vé phía người dùng).

*Lưu ý: Không dùng đuôi .jpeg, chỉ dùng .png hoặc .jpg.*
