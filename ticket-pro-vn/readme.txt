A secure, lightweight, and high-performance customer support ticket system for WordPress with optional Pro upgrades.

== Description ==

Ticket Pro VN delivers a streamlined, fast, and secure support ticket management experience directly inside WordPress. Designed for businesses, agencies, and online stores, it allows customers to submit inquiries, track replies, and communicate with support staff while keeping data safe and private.

### Free Features (Ready to use out of the box)

* **Unlimited Tickets & Conversations**: No artificial limit on tickets, customers, or messages.
* **Frontend Customer Portal**: Automatically sets up dedicated "Submit a Ticket" and "My Support Tickets" pages with shortcodes `[tpv_submit_ticket]` and `[tpv_my_tickets]`.
* **Central Admin Support Queue**: Review customer requests, filter by status (Open, Answered, Waiting, Closed), and update ticket status directly from the WordPress admin.
* **WooCommerce & Custom Login Friendly**: Seamlessly respects custom login pages or routes WooCommerce customers smoothly to support tickets.
* **Granular Member Access Control**: Enable or suspend support ticket privileges per WordPress user.
* **Multilingual Ready**: Native support for English (default) and Vietnamese with included `.po` and `.mo` language catalogs.

### Pro Features (Unlocked with License Key from OSB.VN)

* **Multi-Format Secure Attachments**: Allow customers and agents to upload images (auto-converted to WebP), PDF, Word, Excel, and Text files up to 50 MB with server-side protection.
* **Support Agent Assignment**: Assign specific tickets to dedicated support staff agents to balance workload.
* **Keyword Blacklist & Link Blocking**: Automatically block tickets containing prohibited spam phrases or unsolicited web links.
* **Customer IP Blocking**: Instantly ban malicious IP addresses from ticket submission with one click.
* **Automated Data Retention & GDPR Tools**: Scheduled automatic purge of stored IP hashes and activity logs.
* **Priority Support & Updates**: Direct priority assistance from the Ticket Pro VN development team.

== Installation ==

1. Upload the `ticket-pro-vn` directory to `/wp-content/plugins/` (or upload the zip via **Plugins > Add New** in the WordPress Admin).
2. Activate the plugin through the **Plugins** screen in WordPress.
3. Core features work immediately! Navigate to **Ticket Pro VN > Settings** to configure basic parameters.
4. (Optional) To unlock Pro features, go to **Ticket Pro VN > License & Pro** and enter your license key from https://osb.vn.

== Frequently Asked Questions ==

= Is Ticket Pro VN free to use? =
Yes! The core ticket system, frontend submission portal, customer ticket history, and admin support desk are 100% free with no limits on tickets or conversations.

= How do I upgrade to Pro? =
Visit https://osb.vn to obtain a Pro license key. Then enter your key under Ticket Pro VN > License & Pro in your WordPress Admin to instantly unlock file attachments, agent assignment, and spam shield tools.

= Does Ticket Pro VN require an external service to work? =
No. The core ticket system is self-hosted directly in your WordPress database and uploads folder. No external service is required for free features.

= How does language switching work? =
Ticket Pro VN automatically uses your site's default language (Settings > General > Site Language) or the language set in each user's WordPress profile. English and Vietnamese are bundled out of the box.
